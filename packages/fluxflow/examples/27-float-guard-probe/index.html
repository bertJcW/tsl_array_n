A device conformance probe rather than a simulation. It runs four candidate non-finite tests over a table of float32 values inside a real compute kernel and reads the answers back, because src/float_guards.js exists entirely on the strength of what this measures. WGSL dropped isnan() and every reference recommends x != x in its place; WGSL also lets an implementation assume non-finite values never occur and fold expressions accordingly, so that test is free to compile to a constant false — and on the device this library was developed against, it does. Every NaN guard in the library was silently inert, which cost a liquid solver that ran correctly for a couple of hundred frames and then collapsed to a point in a single step with every diagnostic reporting healthy. Run this on your own GPU: if the x != x column is red here too, the same trap is waiting in any TSL kernel you write yourself.
