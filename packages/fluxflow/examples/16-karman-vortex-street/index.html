A visual Karman-vortex-street demo built on examples/15-flow-past-cylinder/'s own inflow+outflow+collider+MGPCG pipeline, retuned for an elongated domain, a smaller cylinder, and a deliberate small offset from the domain's own centerline to trigger asymmetric shedding. This port has no viscosity model, so shedding is driven by numerical dissipation and the deliberate asymmetry, not a controlled Reynolds number -- see this example's own main.js header comment for the full explanation. The vorticity canvas is what actually shows the alternating shedding (dye fades too fast downstream to show it on its own) -- look for alternating red/blue bands behind the cylinder. "sim speed" above is how many simulated seconds pass per real second (fps * dt) -- well under 1x means the flow's apparent slowness is GPU throughput, not the chosen physical velocity. Open the console for a periodic diagnostic readout.
