grid.createGridFireSolver2's own sibling for liquids: grid.createGridFlipSolver2 (packages/fluxflow/src/grid/grid_flip_solver2.js) -- a 2D FLIP (fluid-implicit-particle) solver, ported from mantaflow's own flip.cpp and its simplest reference scene, scenes/flip01_simple.py: a fixed particle count seeded once (grid.computeFlipBoxSeed) into a box in one bottom corner, no level set, no particle resampling, no collider -- a closed box only. Each frame: particles advect through the current velocity field, scatter their own velocity onto the grid (P2G, a real GPU atomic scatter -- the first particle-based solver in this port), gravity and pressure projection run as usual, then each particle reads back the grid's own velocity *change* from this step (FLIP) blended with a little of the grid's own new velocity directly (PIC, for stability) -- mantaflow's own 97%/3% default blend. Expect the block of particles to fall and spread out into a puddle at the bottom rather than freezing mid-air or flying apart -- open the console for a periodic diagnostic readout.
